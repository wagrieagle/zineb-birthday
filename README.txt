ZINEB'S 20TH BIRTHDAY WEBSITE
=============================

A responsive romantic birthday microsite made with HTML, CSS and vanilla JavaScript.

HOW TO OPEN
-----------
1. Extract the ZIP file.
2. Open the folder.
3. Double-click index.html to open it in your browser.

For local development, you can also open the folder in VS Code and use the Live Server extension.

CUSTOMIZE
---------
- Edit the English birthday message in index.html.
- Replace the photos in the images/ folder with your own images (keep the filenames the same).
- Change the color themes in style.css.
- The theme selector, photo lightbox, birthday surprise, floating hearts and wish reveal are handled in script.js.

The page uses Google Fonts when internet is available; fallback fonts are included.
All uploaded photos included here are stored locally in the images folder.
